
# SQL Joins Practice

## Overview
This project contains three SQL JOIN exercises using the Classic Models database.

## Questions Covered

### 1. INNER JOIN - Employees and Offices
Retrieves:
- firstName
- lastName
- email
- officeCode

Combines employees and offices using officeCode.

### 2. LEFT JOIN - Products and Product Lines
Retrieves:
- productName
- productVendor
- productLine

Combines products and productlines using productLine.

### 3. RIGHT JOIN - Customers and Orders
Retrieves the first 10 orders:
- orderDate
- shippedDate
- status
- customerNumber

Combines customers and orders using customerNumber.

## SQL Concepts Learned

- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- ON clause
- LIMIT clause
